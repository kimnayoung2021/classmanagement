# 🎓 우리반 레벨업 (Class Management)

> **초등학교 6학년 학급 경제 & 성장 다이어리 웹 애플리케이션**  
> "활동이 곧 화폐가 되고, 화폐가 곧 나의 성장이 되는 학급 생태계"

---

## 🌟 주요 기능

### 1. 🪙 학급 화폐 시스템
- **개별 및 다중 지급/차감**: 학생 개별 또는 전체/선택 학생에게 활동 보상 및 규칙 적용
- **소비 가능 잔액 vs 누적 수입 분리**: 획득한 총 경험치(레벨)는 유지되면서 화폐 소비 가능

### 2. 🎮 게이미피케이션 (레벨 & 경험치)
- 획득한 화폐에 따라 경험치(EXP)가 쌓이고 레벨이 상승
- 직관적인 레벨 뱃지와 프로필 성장 게이지 제공

### 3. 👩‍🏫 교사 모드 (Admin)
- 학급 전체 학생(25명) 현황 일괄 모니터링
- 1인 1역 역할 배정 및 관리
- 학급 상점 물품/쿠폰 등록, 가격 설정 및 관리

### 4. 👦 학생 모드 (User)
- 번호/이름 타일 클릭으로 손쉬운 본인 대시보드 진입 (무로그인 간편 구조)
- 오늘의 1인 1역 실천 체크
- 학급 상점에서 원하는 쿠폰/물품 구매 및 보관함(인벤토리) 확인

---

## 📁 파일 구조

- `index.html`: 메인 웹 애플리케이션 구조 및 UI 레이아웃
- `style.css`: 사용자 친화적이고 직관적인 스타일 및 애니메이션
- `app.js`: 학급 관리, 화폐 트랜잭션, 모드 전환 등 프론트엔드 비즈니스 로직
- `data.js`: 초기 학생 명단(25명), 1인 1역 목록, 상점 아이템 기본 데이터
- `server.js`: 로컬 실행을 위한 경량 서버
- `PRD.md`: 상세 제품 요구사항 정의서 (Product Requirements Document)

---

## 🚀 실행 방법

웹 브라우저에서 `index.html` 파일을 직접 열거나, Node.js 환경에서 아래 명령어로 로컬 서버를 실행할 수 있습니다.

```bash
node server.js
```
브라우저에서 `http://localhost:3000` 접속
